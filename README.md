# Pawmart 🐾

**Pawmart** is a web application designed for pet owners and anyone interested in adopting a pet. It connects pet seekers with pet owners who are looking for a loving home for their pets. The platform allows users to request pet adoptions, and pet owners or admins can review and approve or reject these requests.

This project is a simple but powerful solution that makes pet adoption easier and more accessible to everyone!

---

## 🚀 Features

- **User Authentication:**  
  Secure login and registration with **Firebase Authentication**. User accounts can be created, and users can securely log in to request pets for adoption.

- **Pet Adoption Requests:**  
  Users can browse available pets for adoption, request to adopt them, and track their application status (approved/rejected).

- **Admin Panel:**  
  Admins or pet owners can review adoption requests, approve or reject them, and manage the available pets list.

- **Responsive UI:**  
  The platform is built using **React**, **TailwindCSS**, and **DaisyUI** to ensure a smooth, responsive, and accessible experience across all devices.

- **Axios for Data Fetching:**  
  Fetches data from the backend using **Axios** and updates the UI in real-time, making the application fast and dynamic.

- **Pet Details and Filters:**  
  Users can filter pets based on categories like species, age, or size to find the perfect companion.

## 🛠️ How This Project Can Benefit Others

- **Easier Pet Adoption Process:**  
  Pawmart simplifies the process of adopting a pet by providing an easy-to-use platform where pet seekers can directly request to adopt pets, cutting down the barriers between owners and adopters.

- **Admin Management:**  
  Admins or pet owners can efficiently manage adoption requests, ensuring that pets are only adopted by responsible owners who are ready for the commitment.

- **Scalable Solution:**  
  The application is built using modern tools that can easily scale. More features such as pet health tracking, pet accessories shopping, and a community section for pet lovers can be added in the future.

- **Mobile-Friendly Interface:**  
  With the responsive design using **TailwindCSS** and **DaisyUI**, users can access the platform from mobile devices without any issues.

- **Seamless Adoption Process:**  
  The flow of adoption requests, from the user making a request to the admin approving it, makes the adoption process smoother and more transparent for all parties involved.
